### ✦ Philosophy & What I Do

I treat code as an extension of design. Rather than throwing designs over the fence, I engineer end-to-end user experiences with a focus on speed, motion fidelity, and solid backend systems.

- 🎨 **Design Engineering:** Prototyping design systems, components, and responsive views inside **Figma**, then translating them to zero-runtime **Tailwind CSS**.
- ⚡ **Fluid Frontends:** Writing typed, modular code using **Next.js (App Router)** and **React**, punctuated by 60 FPS spring animations with **Framer Motion**.
- ⚙️ **Modern APIs & Services:** Architecting scalable RESTful backends using **Node.js**, **Express**, and high-performance **FastAPI (Python)**.
- 🗄️ **Data Integrity:** Modeling schemas, relationships, and queries across **PostgreSQL**, **MySQL**, and **MongoDB**, with real-time support via **Firebase**.
